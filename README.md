# Nosorogus — Android Apps & Games Developer Page

Официальная веб-страница разработчика мобильных игр и приложений **Nosorogus** в Google Play Store.

- **Профиль в Google Play:** [Nosorogus Developer Profile](https://play.google.com/store/apps/developer?id=Nosorogus)
- **Игры и приложения в каталоге:**
  - **Chef's Challenge: Meal Prep Sprint** (`ru.abersdorf.kitchenbattle`) — кулинарный тайм-менеджмент с управлением жестами и контролем конфорок.
  - **Our Solar System** (`ru.nosorogus.solarsystem`) — интерактивный познавательный атлас планет и объектов Солнечной системы.

## Особенности сайта
- ⚡ **Быстрая загрузка без тяжелых фреймворков:** Чистый Vanilla HTML5, CSS3, JavaScript.
- 🎨 **Современный светлый дизайн:** Выверенная редакторская эстетика, типографика Space Grotesk + Plus Jakarta Sans, мягкие тени и глубина.
- 🌐 **Двуязычный интерфейс:** Мгновенное переключение языков (RU / EN).
- 🎬 **Интерактивные модальные окна:** Просмотр официального видео-трейлера с YouTube и полноэкранный Lightbox для скриншотов в высоком разрешении.
- 📱 **Адаптивность:** Идеальное отображение на смартфонах, планшетах и широких мониторах.
- 🚀 **Готовность к GitHub Pages:** Корректная структура статических файлов, наличие `.nojekyll`, SEO-метаданных и карты сайта.

Подробная инструкция по размещению страницы на GitHub Pages доступна в файле [DEPLOYMENT.md](DEPLOYMENT.md).
