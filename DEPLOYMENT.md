# Инструкция по размещению сайта на GitHub Pages

Данный сайт полностью статичен (чистый HTML5, CSS и JavaScript) и готов к немедленной публикации на **GitHub Pages** без сборки и настройки серверов.

Файл `.nojekyll` уже включен в корень проекта, что гарантирует правильную загрузку всех стилей и скриптов в обход движка Jekyll.

---

## Вариант 1. Размещение через веб-интерфейс GitHub (без терминала)

1. Перейдите на [GitHub.com](https://github.com) и войдите в свой аккаунт.
2. Нажмите **New repository** (Создать новый репозиторий).
3. Задайте имя репозитория:
   - Если хотите адрес вида `https://<ваш_логин>.github.io/`, назовите репозиторий точно: `<ваш_логин>.github.io`
   - Либо укажите любое имя, например `nosorogus` (тогда адрес будет `https://<ваш_логин>.github.io/nosorogus/`).
4. Убедитесь, что репозиторий выбран как **Public** (Публичный).
5. Нажмите **Create repository**.
6. На странице пустого репозитория нажмите ссылку **uploading an existing file** (загрузить существующие файлы).
7. Перетащите в окно браузера все файлы из папки проекта:
   - `index.html`
   - `css/` (с файлом `style.css`)
   - `js/` (с файлом `app.js`)
   - `.nojekyll`
   - `robots.txt`, `sitemap.xml`, `README.md`
8. Нажмите зеленую кнопку **Commit changes**.
9. Перейдите во вкладку репозитория **Settings** (Настройки) -> слева выберите раздел **Pages**.
10. В блоке **Build and deployment**:
    - В выпадающем списке **Source** выберите **Deploy from a branch**.
    - В строке **Branch** выберите ветку `main` (или `master`) и папку `/(root)`.
    - Нажмите **Save**.
11. Через 1-2 минуты GitHub Pages скомпилирует страницу, и вверху появится зеленая плашка со ссылкой на ваш сайт.

## Вариант 2. Размещение через Git в терминале (командную строку)

Если у вас установлен Git и настроен доступ к GitHub (SSH или токен):

1. Откройте терминал в папке проекта:
   ```bash
   cd /home/ubuntu/dev/projects/my/sites/nosorogus-dev
   ```

2. Инициализируйте репозиторий и сделайте первый коммит:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Nosorogus Android Developer Landing Page"
   git branch -M main
   ```

3. Создайте новый публичный репозиторий на GitHub (например, `nosorogus`).

4. Привяжите удаленный репозиторий и отправьте код:
   ```bash
   git remote add origin https://github.com/<ВАШ_АККАУНТ>/nosorogus.git
   git push -u origin main
   ```

5. Включите GitHub Pages:
   - Откройте репозиторий на GitHub: `https://github.com/<ВАШ_АККАУНТ>/nosorogus/settings/pages`
   - В разделе **Branch** выберите ветку `main` и каталог `/ (root)`.
   - Нажмите **Save**.

## Использование собственного домена (Custom Domain, по желанию)

Если вы решите привязать собственный домен (например, `nosorogus.dev`):
1. В настройках **Settings -> Pages -> Custom domain** введите ваше доменное имя и нажмите **Save**.
2. GitHub автоматически создаст файл `CNAME` в корне репозитория.
3. У своего DNS-провайдера добавьте A-записи, указывающие на IP-адреса GitHub Pages:
   - `185.199.108.153`
   - `185.199.109.153`
   - `185.199.110.153`
   - `185.199.111.153`
4. Отметьте галочку **Enforce HTTPS** в настройках репозитория.
